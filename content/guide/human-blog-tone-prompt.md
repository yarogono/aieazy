# AI 말투를 인간적인 블로그 말투로 바꾸는 작성 가이드

AI 쉬움의 글은 정보성 글이어도 딱딱한 설명문처럼 보이면 안 됩니다.
검색 의도에 바로 답하되, 실제 블로거가 독자에게 차분히 설명하는 느낌으로 씁니다.

단, 확인하지 않은 내용을 직접 경험처럼 꾸미면 안 됩니다.
실제 경험이 없을 때는 `공식 안내 기준으로는`, `현재 화면 기준으로 보면`, `테스트 환경에서는`처럼 검증 기준을 드러냅니다.

## 절대 피할 표현

아래 표현은 AI가 쓴 글처럼 보이기 쉬워서 쓰지 않습니다.

- 아시다시피
- 결론적으로
- 요약하자면
- 마지막으로
- 본 글에서는
- ~에 대해 알아보겠습니다
- 다음과 같습니다
- 뿐만 아니라
- 게다가
- 더 나아가
- 반면에
- 따라서
- 흥미롭게도
- 놀랍게도
- 중요한 점은
- 이를 통해
- 효율적으로 활용할 수 있습니다
- 다양한 기능을 제공합니다
- 사용자 경험을 향상시킵니다

## 문장 구조 규칙

문장은 모바일에서 읽기 좋게 짧게 끊습니다.
한 문장은 가능하면 25자 안팎으로 씁니다.

다만 모든 문장을 똑같이 짧게 만들면 기계적으로 보입니다.
짧은 문장과 조금 긴 문장을 섞어서 리듬을 만듭니다.

좋은 흐름:

```md
처음엔 어디서 결제해야 하는지 헷갈릴 수 있어요.
웹에서 결제했는지, 앱에서 결제했는지에 따라 해지 위치가 달라지거든요.

먼저 어디서 결제했는지부터 확인해보세요.
```

피할 흐름:

```md
챗GPT 구독 취소 방법은 다음과 같습니다.
먼저 설정에 들어갑니다.
이후 결제 메뉴를 선택합니다.
마지막으로 취소 버튼을 클릭합니다.
```

## 문단 줄바꿈 규칙

마크다운 원고에서는 한 문단을 너무 길게 붙이지 않습니다.
모바일 화면에서 3줄 이상 길게 늘어질 문단은 나눕니다.

기본 원칙:

- 한 문단은 1~2문장 중심
- 설명이 길어지면 중간에 빈 줄 추가
- 단계 안내는 문장으로 늘어놓지 말고 목록 사용
- 가격, 환불, 결제 글은 표를 적극 사용
- CTA 앞뒤에는 빈 줄을 둬서 광고처럼 묻히지 않게 함

예시:

```md
챗GPT Plus는 매달 자동결제됩니다.
한 달만 써볼 생각이라면 결제 직후 다음 결제일을 메모해두는 게 좋아요.

앱에서 결제했다면 ChatGPT 안이 아니라 App Store나 Google Play에서 해지해야 합니다.
여기서 많이 헷갈립니다.
```

## 블로그 말투 규칙

기본 톤은 친근한 존댓말입니다.
정보는 정확하게, 말투는 사람처럼 씁니다.

어려운 기획자 말투는 쉬운 말로 바꿉니다.
독자가 검색으로 들어온 일반 사용자라는 점을 잊지 않습니다.

| 딱딱한 표현 | 쉬운 표현 |
| --- | --- |
| 대안 | 다른 방법, 다른 선택 |
| 경로 | 방법, 결제한 곳, 들어가는 곳 |
| 전환 | 바뀜, 넘어감 |
| 기준 | 확인할 점, 고르는 기준 |
| 프로모션 | 이벤트 할인 |
| 대상 | 받을 수 있는 사람 |
| 조건 | 규칙, 확인할 점 |
| 비용 절감 | 돈 아끼기, 구독료 줄이기 |
| 공식 결제 | 정식 결제 |
| 계정 방식 | 계정을 쓰는 방식 |

사용하기 좋은 어미:

- ~해보세요
- ~하면 돼요
- ~할 수 있어요
- ~가 좋습니다
- ~가 편합니다
- ~거든요
- ~더라고요
- ~일 수 있어요
- ~부터 보세요

같은 어미가 3번 이상 반복되면 어색합니다.
`~입니다`, `~합니다`만 이어지지 않게 문장을 섞습니다.

예시:

```md
정식 결제가 가장 깔끔합니다.
내 계정에서 직접 관리할 수 있으니까요.

다만 한 달만 써볼 거라면 비용이 부담될 수 있어요.
이럴 때는 할인 구독 가격도 같이 비교해보는 게 좋습니다.
```

## 독자 공감과 질문 사용

독자가 실제로 고민할 만한 질문을 자연스럽게 넣습니다.
억지 감탄사나 과한 리액션은 쓰지 않습니다.

좋은 질문:

- "한 달에 2만 원 넘게 계속 내기엔 조금 부담되죠."
- "무료로 충분한지, Plus까지 가야 하는지 헷갈릴 수 있어요."
- "결제는 했는데 어디서 해지해야 하는지 막힐 때가 있습니다."
- "정식 가격만 보면 간단해 보이는데, 실제로는 어디서 결제했는지가 중요합니다."

피할 질문:

- "저만 그런가요?"
- "이웃님들도 그러시죠?"
- "깜짝 놀라셨죠?"
- "대박이죠?"

AI 쉬움은 네이버 일상 블로그가 아니라 정보형 블로그입니다.
친근하되 과하게 수다스럽지 않게 씁니다.

## 경험 표현 규칙

직접 확인한 내용만 경험처럼 씁니다.
확인하지 않은 경험담을 만들지 않습니다.

쓸 수 있는 표현:

- "제가 확인한 화면에서는 이렇게 보였습니다."
- "정식 도움말을 보면 이 방법이 가장 안전합니다."
- "테스트 환경에서는 버튼이 아래쪽에 있었습니다."
- "처음 보면 이 부분이 조금 헷갈릴 수 있어요."

피할 표현:

- "제가 써보니 무조건 좋았습니다."
- "직접 결제해봤는데 최고였어요."
- "대부분 다 환불됩니다."
- "모든 카드가 문제없이 됩니다."

## 제목 작성 규칙

제목은 검색어를 앞에 둡니다.
그 뒤에 세부 키워드와 후킹 문구를 붙입니다.

형식:

```md
주 키워드 세부 키워드1 세부 키워드2, 후킹 문구
```

예시:

- 챗GPT 가격 플러스 요금제 할인 방법, 결제 전 이 글부터 보세요
- 챗지피티 할인 공유 구독 쿠폰, 가장 싸게 쓰는 방법 정리
- 커서 AI 가격 Pro 요금제 사용량 제한, 개발자라면 결제 전 확인하세요

후킹 문구는 애매하게 쓰지 않습니다.
독자가 왜 클릭해야 하는지 바로 보여줘야 합니다.

좋은 후킹:

- 결제 전 이 글부터 보세요
- 돈 내기 전에 확인할 것
- 괜히 비싸게 쓰지 마세요
- 월 구독료 줄이는 방법
- 지금 받을 수 있는지 확인하기
- 여러 개 결제하기 전에 보세요

피할 후킹:

- 정리해드립니다
- 알아보겠습니다
- 참고하세요
- 확인해보세요
- 좋은 방법

## 제휴 CTA 작성 규칙

제휴 링크는 설명문처럼 쓰지 않습니다.
한국 블로그의 배너처럼 짧고 명확하게 씁니다.

CTA 라벨은 독자가 바로 이해할 수 있어야 합니다.

좋은 라벨:

- 월 구독료 아끼기
- 정가 결제 전 확인
- 결제 전 마지막 체크
- 할인 가격 비교
- 한 달만 써볼 때

좋은 버튼:

- 지금 할인받기
- 지금 구매하기
- 할인 가격 비교하기
- 구독료 줄이기
- 할인 코드 적용하기

피할 버튼:

- 할인 먼저 확인
- 자세히 알아보기
- 가격 확인하기
- 더 알아보기
- 관련 정보 보기

CTA 설명은 1~2줄로 끊습니다.
버튼 앞에는 바로 행동할 이유를 줍니다.

예시:

```md
월 구독료가 부담된다면 정가로 결제하기 전에 할인 가격을 비교해보세요.
한 달만 써볼 예정이라면 차이가 꽤 큽니다.

[지금 할인받기]
```

## 글 작성 전 체크리스트

- 제목 앞쪽에 실제 검색 키워드가 있는가?
- 첫 문단에서 독자가 찾는 답을 바로 줬는가?
- 문단이 1~2문장 중심인가?
- 모바일에서 한 덩어리로 길게 늘어지지 않는가?
- 금지 표현을 쓰지 않았는가?
- `~입니다/합니다`가 계속 반복되지 않는가?
- 확인하지 않은 경험담을 만들지 않았는가?
- CTA가 행동형 문구로 되어 있는가?
- 제휴 고지가 버튼 주변에 자연스럽게 있는가?
