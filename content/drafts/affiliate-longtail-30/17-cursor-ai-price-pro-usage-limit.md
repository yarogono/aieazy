커서 AI는 단순 월 구독료보다 사용 횟수 구조가 더 중요해요.  
Agent를 자주 쓰는 개발자라면 Pro 가격만 보고 결제했다가 사용 횟수가 빨리 닳는다고 느낄 수 있어요.

## 커서 AI 가격 한눈에 보기

Cursor 정식 안내를 보면 개인 요금제는 Free, Pro, Pro Plus, Ultra로 나뉘어요.  
Pro는 월 20달러, Pro Plus는 월 60달러, Ultra는 월 200달러로 안내돼요.

| 요금제 | 맞는 사용자 |
| --- | --- |
| Free | 가볍게 체험 |
| Pro | Tab과 Agent를 적당히 쓰는 개발자 |
| Pro Plus | Agent를 거의 매일 쓰는 개발자 |
| Ultra | 여러 Agent와 자동화를 많이 쓰는 파워 유저 |

## 사용 횟수 제한이 중요한 이유

Cursor는 요금제별로 포함 사용 횟수가 있고, 모델마다 소비되는 비용이 달라요.  
Sonnet, Gemini, GPT 계열 모델을 어떻게 쓰는지에 따라 체감 사용 횟수가 달라집니다.

정식 안내에서는 Pro가 한도적인 Agent 사용자에게 맞고, 매일 Agent를 많이 쓰면 Pro Plus 이상이 필요할 수 있다고 설명해요.

## 결제 전 체크

평소에 자동완성만 많이 쓰는지, Agent에게 파일 수정까지 맡기는지 나눠보세요.  
자동완성 중심이면 Pro로도 충분할 수 있고, Agent 중심이면 더 높은 요금제를 비교해야 해요.

커서 AI는 개발 시간을 줄여주지만, 사용 횟수 구조를 모르면 예상보다 빨리 한도를 만날 수 있어요.
