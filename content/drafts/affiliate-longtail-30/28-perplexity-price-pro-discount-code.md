퍼플렉시티는 검색과 출처 확인에 강한 AI예요.  
Pro 구독을 고민한다면 가격보다 내가 “출처 있는 답변”를 얼마나 자주 필요한지 먼저 봐야 해요.

## 퍼플렉시티 Pro 한눈에 보기

Perplexity 도움말을 보면 Pro 구독은 웹, iOS, Android에서 신청할 수 있고, 결제와 취소 방법가 플랫폼마다 달라요.  
할인 코드나 쿠폰은 계정마다 조건과 만료일이 있을 수 있어요.

| 확인 항목 | 볼 내용 |
| --- | --- |
| Pro 가격 | 결제 화면 기준 |
| 쿠폰 | 만료일, 1계정 1코드 여부 |
| 취소 | 웹, iOS, Android 방법 구분 |
| 환불 | 월간/연간 조건 차이 |

## 할인 코드는 어떻게 써야 할까

Perplexity 도움말에는 쿠폰은 개인 사용용이며, 만료된 코드는 다시 활성화할 수 없다고 안내돼요.  
여러 쿠폰을 한 계정에 동시에 적용할 수 없는 점도 확인해보세요.

검색 결과에 나온 코드를 그대로 믿기보다 결제 화면에서 실제 적용되는지 확인하세요.  
적용이 안 되면 만료되었거나 받을 수 있는 사람 계정이 아닐 수 있어요.

## 결제 전 추천

최신 뉴스, 논문, 자료 조사처럼 출처가 중요한 검색을 자주 한다면 Pro가 맞을 수 있어요.  
단순 대화형 AI가 필요하다면 ChatGPT나 Gemini와 비교해보세요.
